# 桌面窗口契约

- 气泡始终是独立入口；点击展开/收起，拖动移动。展开时仍可点击气泡收起。
- 气泡默认不获取焦点。输入面板打开时获取焦点；失焦保持展开，不自动关闭、不持续抢回焦点。
- Esc 收起面板。面板中的动作菜单打开时，第一次 Esc 关闭菜单。
- 窗口位置按当前显示器工作区与 scale factor 计算，支持负坐标。恢复的气泡位置不在任一工作区时采用默认位置。
- UI 报告期望高度，Rust 限制到工作区；菜单尺寸必须参与期望高度，CSS overflow 不能代替原生窗口扩容。
- 气泡/面板隐藏任务栏图标并置顶；管理页为普通窗口。关闭窗口隐藏，只有托盘退出终止应用。
- 托盘提供输入、气泡显隐、任务、配置、配置目录、退出。隐藏气泡不能让用户失去托盘恢复入口。
- 系统通知须在安装后的 Windows 应用验收；开发时名称/图标可能显示为 PowerShell。通知不含用户输入和完整结果。
- Windows 是支持目标；其他平台主要用于核心测试和浏览器 UI 验证，不承诺桌面效果一致。
