# 配置、路径与托管脚本契约

- 配置目录是用户主目录下 `.config/bullet`，Windows 使用原生用户主目录，不使用 AppData 或 WSL HOME。
- config.json 中的 `version` 是格式版本，当前为 1。类型和字段以 [model.rs](model.rs) 为准；未知字段必须报错，避免静默误配置。
- 首次运行写入默认配置和文本整理 Python 脚本。无效的初始配置阻止启动，不覆盖用户文件；运行中的无效或不可读外部修改保留最后有效配置并返回 warning。`revision` 始终属于最后有效配置；`diskStatus` 区分 valid、invalid、unavailable。可读且不超过 2 MiB 的文件均有内容哈希 `diskRevision`，包括无效 JSON；不可读或超容量时为 null。有效时两个 revision 相同。
- JSON 草稿解析只反序列化，使用 Rust 类型默认值并拒绝类型错误和未知字段；不校验执行完整性、不写文件。启动、载入、保存和恢复才进行完整配置校验。停用动作可缺少执行字段，包括 Script 的独立 {{script}} 参数；ID 唯一性、名称与 cwd/脚本扩展名的路径安全校验仍生效。动作错误关联名称或 ID。
- 每次打开面板、载入配置和启动任务都重新检查文件。没有后台文件监视器，手工修改不是即时推送。
- 普通保存必须要求当前文件有效并比较调用方 revision 与当前文件内容哈希；无效文件只能明确恢复，传入无效文件的哈希也不能绕过普通保存限制。冲突不能无条件覆盖，不自动重试。
- 明确恢复仅接受当前可读、容量内、仍无效且 diskRevision 匹配的文件。替换前将原始字节备份到 recovery/<hash>.json，并校验备份内容；已有完整备份可以复用，写入或校验失败不得替换。备份后再次检查当前字节，外部变化则拒绝；恢复成功或备份后替换失败报告备份位置。替换失败保留旧文件，下一次必须由调用方再次明确尝试。
- 原子替换沿用 tempfile 的同目录持久化实现，不提高权限、不自动清除只读属性。I/O 错误包含目标路径、失败阶段和底层错误码。原子替换保证本进程写入不暴露半个 JSON；复查仍无法消除不遵守协议的外部编辑器在检查和替换之间的竞态。
- Script 源码在 scripts/<actionId>/main.<extension>，ID 与扩展名经过路径安全校验。动作改名不改路径，移除动作保留源码。
- 执行使用 scripts/<actionId>/versions/<hash>/main.<extension> 的不可变版本。`__file__`/模块位置在版本目录；cwd 与此无关。单文件脚本不自动复制相邻资产。版本保留，不自动删除正在或曾经运行的源码。
- 脚本源和动作配置分别保存，各自有 revision；两者不是跨文件事务。试运行先保存配置和脚本再执行，错误必须可见。
- defaultCwd 为绝对路径、~、~/... 或 ~\...；不支持 ~用户名。校验与执行共享 cwd 语法，并忽略首尾空白。Rust 启动、载入、保存和恢复统一规范化 cwd，空动作 cwd 转为继承；不改变程序名或参数内容。动作相对 cwd 以 defaultCwd 为基准，~ 路径以用户主目录为基准。Windows 驱动器相对 cwd 与无驱动器根路径必须拒绝。
- 目录不存在时拒绝启动，保留用户输入；不创建目录、不回退到其他目录、不修改全局 cwd。
- 程序名允许直接配置 pi、uv、python。Unix 的裸名称由 Command 使用子进程 PATH 查找；Windows 按有效 PATH 的目录顺序和 PATHEXT 中 .com/.exe/.bat/.cmd 的顺序定位入口，缺少 PATHEXT 时使用该默认列表。动作 env 中的 PATH/PATHEXT 覆盖应用继承值，Windows 变量名不区分大小写。
- Windows 不隐式搜索启动器目录或当前工作目录。相对 PATH 项以动作 cwd 为基准，空项跳过；驱动器相对项如 C:bin 不参与查找。带路径的程序相对 cwd 解析，驱动器相对程序路径 C:foo 必须拒绝。已指定扩展名的存在文件优先使用原路径。
- npm 的无扩展名 Unix shim 不作为 Windows 裸命令入口，查找 pi 可以命中 pi.cmd。启动时取得的绝对路径仅属于本次执行，不回写用户配置。修改系统 PATH 后需要重启常驻应用；不载入 PowerShell profile、alias 或函数。
- 普通参数按数组传给 Command；Windows .cmd/.bat 由 Rust 标准库处理批处理转义，不自行拼接 cmd /c 命令字符串。仅参数输入模式替换 {{input}} 与 {{input-inline}}；Script 的独立 {{script}} 参数替换为源码快照绝对路径。
- {{input}} 原样插入（多行保留）；{{input-inline}} 是输入的 JSON 字符串转义体（不含首尾引号），适用于字符串本身是 JSON 文本的插值点，也天然产出单行文本。两种占位符单遍替换，插入文本不再扫描，输入中的占位符字面量不会递归；语义在参数与 HTTP 处一致，是否适用由用户判断，脚本源码不参与替换。
- stdin 输入完成后必须关闭，包括空输入。脚本是配置好的代码，用户输入是数据。
- HTTP JSON 中的占位符只替换字符串值再序列化，内层 JSON 文本由服务侧追加解析；环境变量引用 ${env:NAME} 只用于 HTTP 请求头。不会在任意字段执行模板代码。
